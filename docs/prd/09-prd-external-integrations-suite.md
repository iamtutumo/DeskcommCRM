# Sub-PRD 09 — External Integrations Suite (EgoSMS, Documenso, HeyForms, IdSwyft, MinIO)

> Defines the comprehensive architectural roadmap and menu for integrating five critical external microfinance ecosystem providers into DeskcommCRM: **EgoSMS** (Uganda/East Africa SMS Gateway), **Documenso** (Open-Source Digital Signatures), **HeyForms** (Onboarding & KYC Forms), **IdSwyft** (`Weareupsyd/idswyft-community-W` KYC Identity Verification), and **MinIO** (Self-Hosted S3 Object Storage for Generated Documents).

---

## 1. Executive Summary & Why Odoo 17 (`ijayo-odoo-17`) Cluttered Integrations

In the Odoo 17 ERP approach (`ijayo-odoo-17`), connecting external tools required installing rigid Python third-party modules or writing brittle custom scripts that bypassed Odoo's security permissions.
* Documents were split between Odoo's internal database (`ir.attachment`) and external storage without unified signed URL lifecycle control.
* KYC verification (IdSwyft) and e-signatures (Documenso) lacked conversational orchestration on WhatsApp.
* SMS notifications (EgoSMS) required hacking Odoo's default SMS gateway provider.

DeskcommCRM solves this by implementing a **Unified External Integrations Menu and Core Adapter Layer (`lib/integrations/external/`)**. Every provider is exposed via a standardized interface, integrated into the tenant settings UI, and made accessible to AI agents via **MCP Tools (`external_send_sms_egosms`, `external_verify_kyc_idswyft`, `external_create_signature_documenso`, `external_get_storage_url_minio`)**.

### 2.1 EgoSMS (`egosms` — Uganda & East Africa SMS Gateway)
* **Operational Purpose:** Sends SMS OTPs, loan approval notices, payment reminders, and critical arrears alerts across Uganda and East Africa.
* **How We Integrate:**
  * Configured in the External Integrations Menu via `username`, `password`, `sender_id`, and `api_url` (`https://www.egosms.co/api/v1/json/`).
  * `EgoSmsAdapter.sendSms(to, message)` formats phone numbers to East African E.164 standards (`+256...`) and dispatches messages.
  * AI agents can trigger SMS alerts via MCP tool `external_send_sms_egosms` when internet/WhatsApp connectivity is unavailable.

### 2.2 Documenso (`documenso` — Open-Source Digital Signatures)
* **Operational Purpose:** Digitally signs formal PDF Loan Agreements and Promissory Notes generated by `@react-pdf/renderer`.
* **How We Integrate:**
  * Configured via `api_key`, `api_url`, and `webhook_secret`.
  * When a loan reaches stage `"3. Approved / Signature"`, `DocumensoSignatureAdapter.createSigningRequest(documentId, signerEmail, signerName)` creates an open-source Documenso signing request.
  * The signing link is automatically sent to the borrower via WhatsApp (Evolution API) and Email (Standard SMTP).
  * When Documenso emits the webhook `document.signed`, DeskcommCRM advances the card to `"4. Disbursed"`.

### 2.3 HeyForms (`heyforms` — Open-Source Onboarding Forms)
* **Operational Purpose:** Collects custom online loan application forms, guarantor questionnaires, and asset disclosures.
* **How We Integrate:**
  * Configured via `api_key`, `api_url`, and `webhook_secret`.
  * HeyForms webhooks ingest submitted responses into `/api/v1/webhooks/in/<token>`, automatically creating a new `crm_lead` in `"1. Simulation & KYC"` and mapping custom form fields into `contact` properties.

### 2.4 IdSwyft (`idswyft` — KYC Identity Verification Platform)
* **Operational Purpose:** Validates national identity cards, passports, biometric selfies, and credit compliance (`Weareupsyd/idswyft-community-W`).
* **How We Integrate:**
  * Configured via `api_key`, `api_url`, and `confidence_threshold` (default `85%`).
  * When a borrower uploads a photo ID in WhatsApp, `IdSwyftKycAdapter.verifyIdentity(contactId, documentNumber, documentType, photoUrl)` submits the image to IdSwyft.
  * The resulting KYC score and verification status (`verified`, `rejected`, `manual_review`) are recorded in the record's Audit Trail and Chatter, and accessible to the AI agent via MCP tool `external_verify_kyc_idswyft`.

### 2.5 MinIO (`minio` — Self-Hosted S3 Object Storage)
* **Operational Purpose:** Replaces external cloud S3 with self-hosted **MinIO** object storage for all generated PDF agreements, KYC attachments, and promissory notes.
* **How We Integrate:**
  * Configured via `endpoint`, `access_key`, `secret_key`, `bucket_name`, and `use_ssl`.
  * `MinioStorageAdapter.uploadDocument()` stores PDFs generated by `@react-pdf/renderer` directly in MinIO.
  * `MinioStorageAdapter.getSignedUrl()` generates expiring signed URLs for WhatsApp and email attachment delivery.

## 3. External Integrations Menu UI & Architecture

In the CRM UI, a dedicated settings screen (**Tenant Settings > External Integrations**) presents cards for each of the five providers:
* Displays connection status badges (`ready`, `connecting`, `error`, `not_configured`).
* Provides clean input forms for API credentials and webhook secrets.
* Includes a **"Test Connection"** button that invokes synchronous health checks on the provider.

---

## 4. Success Metrics

* 100% of generated microfinance documents stored securely on self-hosted MinIO with expiring signed URL access.
* <5-second automated KYC identity verification through IdSwyft integration.
* Seamless digital agreement signature turnaround using Documenso and WhatsApp Evolution API.
* Reliable SMS reminder delivery across Uganda via EgoSMS.
