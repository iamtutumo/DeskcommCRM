# Technical Specification 20 — External Integrations Suite (EgoSMS, Documenso, HeyForms, IdSwyft, MinIO)

> Technical specification for Sub-PRD 09. Defines the database schema, adapter contracts in `lib/integrations/external/`, MCP tools in `lib/mcp/tools/external-integrations.ts`, and invariants governing connection to five external microfinance ecosystem providers.

## 2. Business Rules & Invariants

* **E-01 (External Adapter Abstraction):** Every external provider must implement a standardized adapter interface with typed configuration and status checking (`isConfigured()`, `testConnection()`).
* **E-02 (EgoSMS E.164 Normalization):** SMS phone numbers processed by `EgoSmsAdapter` must be formatted to East African E.164 standards (`+256...`).
* **E-03 (MinIO Signed URL Expiration):** Document URLs generated by `MinioStorageAdapter.getSignedUrl()` must enforce an expiration timestamp (default: `72 hours`).
* **E-04 (IdSwyft KYC Confidence Threshold):** Verification scores returned by `IdSwyftKycAdapter` below the organization's configured threshold (default: `85%`) must transition the borrower status to `manual_review` and alert a human officer.
* **E-05 (Documenso Webhook HMAC Verification):** Webhooks received from Documenso (`document.signed`) must be verified using HMAC SHA-256 against `webhook_secret`.
* **E-06 (HeyForms Field Mapping):** Webhook payloads ingested from HeyForms must cleanly map to canonical `contact` and `crm_lead` properties.
* **E-07 (MCP Tool Reachability):** The 4 external integration MCP tools (`external_send_sms_egosms`, `external_verify_kyc_idswyft`, `external_create_signature_documenso`, `external_get_storage_url_minio`) must be declared in `TOOL_CATALOG` and registered in `allTools`.
* **E-08 (Strict Tenant RLS Isolation):** The `tenant_external_integrations` table enforces organization-level Row Level Security (`organization_id = ANY (fn_user_org_ids())`).

## 3. Database Model (`supabase/migrations/20260808200000_0135_external_integrations_suite.sql`)

* `tenant_external_integrations`: Stores per-organization provider configuration (`provider: 'egosms' | 'documenso' | 'heyforms' | 'idswyft' | 'minio'`, `config_json`, `status`, `last_synced_at`).
* Enforces Row Level Security (`organization_id = ANY (fn_user_org_ids())`).

---

## 4. TypeScript Service & Adapter Layer (`lib/integrations/external/`)

1. `types.ts`: Domain configuration and result types for EgoSMS, Documenso, HeyForms, IdSwyft, and MinIO.
2. `registry.ts`: Metadata catalog for the External Integrations UI Menu (label, icon, description, documentation link).
3. `adapters/egosms.ts`: `EgoSmsAdapter.sendSms(to, message)` for East Africa SMS delivery.
4. `adapters/documenso.ts`: `DocumensoSignatureAdapter.createSigningRequest(documentId, signerEmail, signerName)`.
5. `adapters/heyforms.ts`: `HeyFormsAdapter.parseWebhookPayload(payload)`.
6. `adapters/idswyft.ts`: `IdSwyftKycAdapter.verifyIdentity(contactId, documentNumber, documentType, photoUrl)`.
7. `adapters/minio.ts`: `MinioStorageAdapter.uploadDocument(bucket, key, buffer)` and `getSignedUrl(bucket, key, ttl)`.
8. `index.ts`: Module exports.
